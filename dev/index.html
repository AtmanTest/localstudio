1. Introduction à la Qualité des Logiciels

Objectif : Comprendre ce qu'est la qualité, pourquoi elle est importante et comment l'évaluer.

ConceptDescription
QualitéDegré dans lequel un produit satisfait des besoins exprimisés ou implicites.
Requêtes de qualitéAttentes, besoins et contraintes imposés par le client.
Attributs de qualitéFaisabilité, efficience, sécurité, fiabilité, etc.

💡 Méthode ISTQB : Qualité = Conformance + Compliance

2. Processus de Test (Test Process)

Objectif : Comprendre le cycle de vie d'un test.

ÉtapeDescription
PlanificationDéfinir les objectifs, scope et stratégie de test.
AnalyseComprendre le système à tester (requirements, architecture).
DesignCréer les tests (cases, techniques de design).
ExécutionLancer les tests et collecter les résultats.
AnalyseInterpréter les résultats, identifier les défauts.

💡 Méthode ISTQB : "You can't manage what you don't measure"

3. Types de Tests (Test Levels)

Objectif : Comprendre les différents niveaux de test.

NiveauCibleExemples
M1 (Unit)Composant interneUnit tests, code coverage
M2 (Integration)Interface entre composantsAPI tests, module tests
M3 (System)Système completEnd-to-end tests, UI tests

💡 Méthode ISTQB : Pyramid Testing — plus de M1 que M2/M3

4. Techniques de Design de Tests

Objectif : Savoir créer des tests pertinents.

TechniqueDescription
Equivalence PartitioningDiviser les entrées en classes équivalentes.
Boundary Value AnalysisTester aux limites des classes (min, max).
Error GuessingAnticiper les erreurs courantes.

💡 Méthode ISTQB : "The more you know about the system, the better your tests."

5. Cycle de Vie du Défaut (Defect Lifecycle)

ÉtatDescription
NewDétection lors d'un test.
OpenAffecté à un développeur.
Fix PendingCorrection en cours.
VerifiedFixé et validé.

💡 Méthode ISTQB : MTTR = Mean Time To Resolution

DFF(D + F) / (D + F)Risque de défaut

💡 Méthode ISTQB : "Measure what you manage"
